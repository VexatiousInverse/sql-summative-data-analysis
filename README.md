# SQL Summative Lab & Exploratory Data Analysis

This repository contains the complete code, visualizations, and exploratory analysis for the SQL Summative Lab.

## Project Structure
- **Part 1:** Guided SQL Queries & Visualizations using `data.sqlite` (Customer behavior, international campaigns, credit limits, top customers, product line analysis, and remote office subqueries).
- **Part 2:** Exploratory Data Analysis using `im.db` (Movie industry baseline metrics, genre engagement analysis, and data cleaning/normalization assessment).
- **Presentation:** Interactive slide deck summarizing Part 2 findings.
